# platform-api

API Gateway CDK stacks (spot, swap, futures, options, metrics, defi-dex) plus a dashboard. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/platform-api-archive`.

Hosted-zone choice uses `CDK_DEV_ACCOUNT`. Generated `cdk.context.json` was **removed**.

No contract deployments recorded in this repo.

## What was built (EN)

platform-api provisions per-product REST APIs on API Gateway (`api.`, `spot.api.`, `swap.api.`, `futures.api.`, `options.api.`, `metrics.api.`, `defidex.api.`) against `dev.euler.tools` / `prod.euler.tools`.

## Qué se construyó (ES)

APIs de plataforma (spot, swap, futuros, opciones, métricas, defi-dex). Contexto CDK de AWS eliminado.
